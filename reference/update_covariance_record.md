# Update the covariance record in a Pharmpy NONMEM model

Update the covariance record in a Pharmpy NONMEM model

## Usage

``` r
update_covariance_record(model, cov_record)
```

## Arguments

- model:

  pharmpy model object or NONMEM model code (character) or path to
  NONMEM model file.

- cov_record:

  new covariance record
