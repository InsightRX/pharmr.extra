# Does the Pharmpy NONMEM model object have a \$COV record?

Does the Pharmpy NONMEM model object have a \$COV record?

## Usage

``` r
has_covariance_record(model)
```

## Arguments

- model:

  pharmpy model object or NONMEM model code (character) or path to
  NONMEM model file.

## Value

TRUE or FALSE
