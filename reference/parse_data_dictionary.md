# Create a dictionary from given specs and default dictionary as fallback

Create a dictionary from given specs and default dictionary as fallback

## Usage

``` r
parse_data_dictionary(
  dictionary,
  default = list(ID = "ID", TIME = "TIME", DV = "DV", EVID = "EVID", AMT = "AMT", CMT =
    "CMT", MDV = "MDV")
)
```
