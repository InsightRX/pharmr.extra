# Extract covariance record from a Pharmpy NONMEM model object

Extract covariance record from a Pharmpy NONMEM model object

## Usage

``` r
get_covariance_record(model)
```

## Arguments

- model:

  pharmpy model object or NONMEM model code (character) or path to
  NONMEM model file.

## Value

\$COVARIANCE record (character)
